# Real Estate CRM

A starter CRM application for real estate teams to manage leads, clients, properties, deals, and tasks.

## Features
- Dashboard overview
- Lead management table
- Property listing cards
- Deals pipeline cards
- Client directory
- Task tracking
- Modern UI with Next.js + Tailwind CSS

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Lucide React icons

## Getting started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Project structure
- `app/` – pages and app shell
- `components/` – layout components
- `data/` – mock data for the CRM

## Customization ideas
- Add a database with PostgreSQL or MongoDB
- Add authentication using NextAuth or Clerk
- Integrate email/SMS reminders
- Connect your own property listings API
- Add charts and advanced reporting

## Notes
This is a starter MVP designed for fast prototyping and UI development. You can extend it into a production-ready system with your own backend and database.
